# Расширяемые характеристики

## Дополнительные характеристики светильника

С ЛР4 схема включает пять таблиц. `lighting_attributes` — справочник: `attribute_id integer PK`, `attribute_name varchar(100) UNIQUE NOT NULL`. `lighting_equipment_attribute_values` — вертикальная таблица значений: `equipment_id integer PK FK`, `attribute_id integer PK FK`, `attribute_value varchar(500) NOT NULL`. Составной PK `(equipment_id, attribute_id)` запрещает повтор одной характеристики у модели; внешние ключи имеют RESTRICT. Это связь м-м между светильниками и атрибутами с собственным значением на связи. У разных светильников наборы различаются; добавление названия и строки значения не требует ALTER TABLE. Единица измерения указывается в имени, например «Цветовая температура, К». Мощность и угол остаются основными фиксированными полями.

`GET /api/lighting-equipment/feed?equipmentId=1` возвращает `attributes: [{attributeId: 1, attributeName: "Цоколь", attributeValue: "E27"}]`. Черновик и ответ публикации тоже содержат `attributes`; без характеристик передаётся `[]`.

- `GET /api/lighting-equipment/attributes` — справочник `{attributeId, attributeName}[]`, доступен гостю.
- `PUT /api/lighting-equipment/{equipment_id}/attributes` — полная замена набора своего неудалённого светильника с JWT. Тело: `{"attributes":[{"attributeName":"Цоколь","attributeValue":"E27"}]}`. Новые имена автоматически создаются в справочнике. `{"attributes":[]}` очищает набор этой модели, сохраняя общий справочник. Нет поля или null — 400; неавторизованный запрос — 401; чужая модель — 403; отсутствующая/удалённая — 404.
- PUT публикации принимает необязательный `attributes` с тем же составом. Отсутствующий массив сохраняет ранее заданные значения, пустой очищает их. Публикация и замена характеристик выполняются в одной транзакции.

До 50 характеристик на модель; имя 1–100 символов, значение 1–500. Пробелы по краям удаляются, пустые строки и повтор одного имени отклоняются с 400. Имена сравниваются с учётом регистра. Удаление строки у модели не удаляет этот атрибут у остальных моделей.

На странице ленты кнопка «Характеристики» открывает список названий и значений. В ЛР5 он берётся только из mock, без Redux и API. В ЛР6 данные поступают из API через сгенерированный Axios-клиент и thunk; создателю доступно «Изменить характеристики». В форме публикации можно добавлять и удалять строки.
